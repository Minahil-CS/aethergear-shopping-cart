## 🎯 One-Line Description
> *A high-performance, institutional-grade e-commerce storefront featuring dynamic cart management, multi-currency conversion, promo code calculations, and an interactive checkout receipt generator.*

---

## 🚀 Pro Features

- **🛒 Dynamic Slide-Over Cart Engine**: Real-time quantity steppers (`-`/`+`), item removal with undo toast notifications, and a dedicated **Save for Later** shelf.
- **🔍 Advanced Product Catalog & Filtering**: Instant search, category filters, sorting options (Price, Rating, Featured), and quick view specs modal.
- **💱 Real-Time Multi-Currency Support**: Seamless currency conversion across `USD ($)`, `EUR (€)`, `GBP (£)`, and `PKR (Rs)`.
- **🎟️ Promo Code & Shipping Calculator**: Instant discount calculation (`PRO20`, `WELCOME15`, `FREESHIP`), free shipping progress bar, and selectable shipping tiers.
- **🧾 Checkout & Printable Digital Receipt**: Complete checkout modal generating a unique Order ID (`#AG-2026-XXXX`) with direct print functionality.
- **💾 Local Storage Persistence**: Remembers your cart items, wishlist saves, and active preferences across sessions.
